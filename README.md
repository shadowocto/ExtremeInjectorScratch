Extreme Injector Scratch
======
A web-based remake of [Extreme Injector](https://github.com/master131/ExtremeInjector) for [Scratch](https://scratch.mit.edu).\
To use Extreme Injector you must install it as an unpacked chrome extension, learn how to do this [here](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked).

Bug Reporting
------
To report any bugs or issues with the injector, please create an [Issue](https://github.com/shadowocto/ExtremeInjectorScratch/issues) on Github.
